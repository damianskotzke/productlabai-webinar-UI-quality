# Fonts

This folder is empty on purpose. PP Neue Montreal is a commercial typeface, so its files are not in the repo.

Put these files here before you run the project:

- `PPNeueMontreal-Medium.woff2`
- `PPNeueMontreal-MediumItalic.woff2`

Get them from [Pangram Pangram](https://pangrampangram.com/products/neue-montreal). If you do not want to get them, use Inter instead. The main README shows how.
